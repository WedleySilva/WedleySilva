## 👨‍💻 Sobre mim

Sou desenvolvedor Full Stack com foco na criação de aplicações escaláveis, APIs e interfaces modernas. 

Gosto de transformar regras de negócio em soluções simples de utilizar e fáceis de manter, sempre priorizando arquitetura limpa, desempenho, segurança e uma experiência consistente para usuários e desenvolvedores. 

Atualmente concentro meus estudos e projetos em Engenharia de Software, desenvolvimento web moderno e boas práticas de arquitetura.
