## 👨‍💻 Sobre mim

Sou **Desenvolvedor Web / Full Stack Software Engineer**, com experiência prática no desenvolvimento de aplicações web, sistemas corporativos e soluções digitais.

Tenho experiência com **frontend, backend, APIs, bancos de dados, regras de negócio, integração de serviços externos e publicação de aplicações em produção**.

Gosto de transformar requisitos e problemas de negócio em soluções organizadas, funcionais e fáceis de manter, com atenção a **arquitetura, segurança, qualidade de código, desempenho e experiência do usuário**.

Atualmente concentro meus estudos e projetos em **Engenharia de Software, desenvolvimento web moderno e arquitetura de aplicações**.
